enumerate() function in Python is a built-in tool that allows you to loop through an iterable (like a list, tuple, or string) while automatically keeping track of the index (position) of each item.

List comprehension in Python is a concise, one-line way to create a new list from an existing iterable.
basic syntax: [expression for item in iterable]  ex:- [x**2 for x in range(10)] prints square of value till 0 to 9
for conditional syntax: [expression for item in iterable if condition] ex:- lsit=[x for x in range(10) if x%2==0] prints even number
for nested list syntax: [expression for item1 in iterable1 for item2 in iterable2] ex:- list=[1,2,3,4]
